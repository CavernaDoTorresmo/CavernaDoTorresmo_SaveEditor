## 🎮 O que é o Save Editor?

Uma ferramenta da **Caverna do Torresmo**, criada para facilitar a edição de perfis dos simuladores da SCS, com interface em português e foco na nova progressão de motoristas de ônibus do **ETS2 Coaches**.

Sem precisar editar os dados manualmente: abra um salvamento compatível, escolha o que quer alterar, revise e salve com backup.

## ✨ Recursos

| Área | O que você encontra |
| --- | --- |
| 🚌 **Coaches — Ônibus** | XP exclusivo de ônibus e as seis habilidades da DLC, com opção de maximizar |
| 👤 **Perfil e dinheiro** | Ajustes de valores disponíveis no save |
| 🚛 **Caminhão** | Progressão e habilidades tradicionais |
| 🏠 **Garagens** | Edição limitada de informações existentes **(experimental)** |
| 🛡️ **Segurança** | Revisão de mudanças, avisos de compatibilidade e backup antes da gravação |

> **Importante:** o editor é uma versão **0.4 RC (pré-lançamento)**. A função Coaches foi validada em um perfil ETS2 real; outros perfis, versões do jogo e mods ainda exigem testes.

## 🚀 Como usar em poucos passos

1. **No jogo**, faça pelo menos uma viagem de ônibus (para inicializar os dados da DLC Coaches, se for usar essa aba).
2. Crie um **salvamento manual**, feche o ETS2/ATS e faça uma cópia da pasta do seu perfil.
3. Abra `CavernaDoTorresmo_SaveEditor.exe` e use **Detectar saves** ou **Abrir game.sii**.
4. Selecione **Coaches — Ônibus**, ajuste os atributos desejados e **revise as alterações**.
5. Clique em **Salvar com backup**.
6. Reabra o jogo e carregue **o mesmo save** para conferir.

📖 Veja o [tutorial detalhado](docs/COMO_USAR.md), incluindo a configuração `g_save_format` e a restauração de backup.

## 🔐 Download seguro

O executável foi compilado para Windows 10/11 de 64 bits e **não exige Python instalado** para os jogadores.

Ao publicar o download, confira também o SHA-256 disponibilizado em [SHA256.txt](SHA256.txt). Esse hash confirma a integridade dos bytes em relação ao arquivo publicado; não é um atestado de ausência de malware.

**SHA-256 do executável v0.4 RC:**
```text
B3DFD83DAD8B54DFD01C8BA330B11B48FAACD03D052104F8663AB32A8232C6BF
```

⚠️ Como o executável não está assinado digitalmente, o Windows SmartScreen poderá exibir um alerta. **Não desative suas proteções.** Confira a procedência do arquivo e sua integridade antes de executar.
